# data09-19 · 엔진 인터페이스 옵션 통합 관리·분석 도구

고객사·장비별 인터페이스 옵션(15가지 정도, 선택지 2~5가지 정도)을 담당자가 항목을 직접 늘릴 수 있는 카탈로그로 통합 관리하고, 고객사·지역·장비 유형별 옵션 사용 빈도·비율을 보여 주는 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 장광희 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 — 프로젝트 기획서 등록 (2026-09-28) |
| 다음 개발 | 옵션 카탈로그(항목·선택지)를 직접 편집하고 레코드 입력·엑셀 가져오기/내보내기, 고객사·지역·장비 유형별 옵션 사용 빈도·비율 피벗과 그래프를 보여 주는 브라우저 도구(데이터는 브라우저·로컬 파일에만 보관) |
