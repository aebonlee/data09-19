# data09-19 · 엔진 인터페이스 옵션 통합 관리·분석 도구

고객사·장비별 인터페이스 옵션(15가지 정도, 선택지 2~5가지 정도)을 담당자가 항목을 직접 늘릴 수 있는 카탈로그로 통합 관리하고, 고객사·지역·장비 유형별 옵션 사용 빈도·비율을 보여 주는 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 장광희 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-09-28) — https://aebonlee.github.io/data09-19/ |
| 다음 개발 | 옵션 카탈로그(항목·선택지)를 직접 편집하고 레코드 입력·엑셀 가져오기/내보내기, 고객사·지역·장비 유형별 옵션 사용 빈도·비율 피벗과 그래프를 보여 주는 브라우저 도구(데이터는 브라우저·로컬 파일에만 보관) |

## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-19/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다. 고객사 정보를 다루므로 **내 PC에서 여는 방법을 권장합니다.** 어느 방법이든 데이터는 서버로 가지 않고 이 브라우저 안에만 저장됩니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 옵션 내역이 비어 있고, 카탈로그에는 제출 원문에 나온 항목(고객사, engine suffix, 장비 유형, 지역, 출력, ATS type, CAN SA, Pedal type, starter control type, check engine lamp)만 들어 있습니다. **「예시 데이터 불러오기」** 를 누르면 가상 고객사 6곳·72건이 들어가고 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

| 메뉴 | 하는 일 |
|---|---|
| 옵션 내역 | 레코드(고객사×장비 1건) 입력·고치기·복제 입력·지우기, 검색·거르기, Excel 가져오기·내보내기 |
| 옵션 카탈로그 | 항목 추가·이름 바꾸기·순서 바꾸기·숨기기, 항목별 선택지 추가·이름 바꾸기·순서 바꾸기·숨기기 |
| 사용 빈도 | 옵션 항목마다 선택지별 건수·비율 막대 (지역·장비 유형·고객사로 거르기) |
| 기준별 비교 | 고객사·지역·장비 유형별로 가장 많이 쓰는 선택지 표, 기준 × 옵션 100% 누적 막대와 피벗 표 |
| 백업·복원 | 전체 데이터 백업 파일(JSON) 저장·복원, Excel 내보내기, 모두 지우기 |

- 데이터는 **이 브라우저(localStorage)에만** 저장됩니다. 브라우저 데이터를 지우면 사라지므로 작업을 마칠 때 「백업·복원」에서 백업 파일을 저장해 두세요.
- 가져오기 연습용 예시 파일: `samples/예시데이터_옵션내역.xlsx`, `.csv` — 열 이름을 영문(Customer, Region …)으로 바꾸고, 표기가 다른 값(CAN, hw type)과 카탈로그에 없는 열(예시 옵션 X)을 일부러 넣었습니다. 모두 가상 데이터입니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 옵션 카탈로그 편집 | 완료 | 항목·선택지 추가·이름 바꾸기·순서 바꾸기, 삭제 대신 숨기기(기록·집계는 유지). 선택지는 id 로 저장해 이름을 바꾸면 기존 레코드에도 반영. 초기값은 원문 예시(check engine lamp: CAN type / HW type)만 |
| 기본 정보 항목 편집 | 완료 | 고객사·engine suffix(글자), 장비 유형·지역(선택 목록), 출력(숫자). 새 기본 정보 항목을 글자·선택 목록·숫자로 추가 |
| 레코드 입력·수정 | 완료 | 한 건씩 입력, 옵션은 카탈로그 선택지 중에서만 고름, 검색·거르기, 복제 입력, 고객사 필수 검사(가정) |
| 엑셀 가져오기 | 완료 | xlsx·csv, 시트·머리행 자동 찾기, 열 매핑(영문 열 이름 자동 연결, 다음부터 같은 열 이름 기억), 카탈로그에 없는 값은 「새 선택지로 추가 / 기존 선택지로 연결 / 비워 둠」, 없는 열은 새 항목으로 추가 |
| 엑셀 내보내기 | 완료 | 옵션 내역·카탈로그·고객사/지역/장비 유형별 최다 옵션 시트, 분석 화면별 내보내기. 내보낸 파일은 다시 가져오기 가능 |
| 옵션 사용 빈도·비율 분석 | 완료 | 옵션 항목별 선택지 건수·비율 막대(미입력 포함), 거르기 |
| 기준별 피벗 | 완료(출력 구간 제외) | 고객사·지역·장비 유형(글자·선택 목록 기본 정보 전부) 기준 최다 선택지 표, 100% 누적 막대와 피벗 표. **출력 구간 기준은 2단계**(구간 기준 확인 필요, 기획서 10장 6번) |
| 로컬 저장·백업 | 완료 | 브라우저 자동 저장, 저장소를 못 쓰면 메모리로 동작하고 안내, JSON 백업·복원 |
| 변경 이력 | 다음 단계 | 2단계 |
| 옵션 조합 분석 | 다음 단계 | 2단계 |
| 표준 사양 후보 추천 | 다음 단계 | 2단계 (지금은 「가장 많이 쓰는 선택지」 표로 대신) |
| AI 요약 | 다음 단계 | 3단계 — 외부 AI 사용 허용 여부 확인 후(기획서 10장 11번) |
