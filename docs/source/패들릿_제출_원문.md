② 해결하고 싶은 현안 1건 (구체적일수록 1차 개발이 정확해져요)
     고객사에서 장비 별로 요구하는 option이 15가지 정도 정해져 있습니다. option 별로 선택 할 수 있는 항목은 2~5가지 씩정도 됩니다. 예를 들어 check engine lamp는 CAN type을 사용 할 수 있고, HW type을 사용할 수 있습니다. 지금 까지 다양한 고객사와 다양한 장비를 개발해 오면서 보안을 위해 고객사 별로 통합 관리하지 않았습니다. 이제는 내부 보안이 강화되어 고객사별 통합 관리하면서 한국, 유럽, 미국 또는 굴삭기, 지게차, 발전기 등에 따른 주로 사용하는 option 특성을 파악하고 추가 개선 가능한 항목을들 검토해 보려고 합니다.    
③ 보유 데이터 유형 (정비 이력·설비 소음 녹음·점검표 사진·도면·부품 Excel·회의 녹음·매뉴얼 등)
   고객사, engine suffix, 장비 유형, 출력, ATS type, CAN SA, Pedal type, starter control type 등등 15개 정도의 항목이 있고 (항목은 제가 추후 임의로 넣을 수 있어야함)
④ 기대 산출물 (예: 정비 트러블슈팅 챗봇, KPI 자동 보고서, 이상 감지 알림)
    고객사, 지역, 장비 타입 별로 많이 사용하는 옵션을 보여 줄 수 있어야함.
